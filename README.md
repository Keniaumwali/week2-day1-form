# Student Registration Form

## Project Description

The Student Registration Form is a simple website that allows students to enter their personal information and select a course they want to study.

This project was created as part of the Week 2, Day 01 GitHub session to practice HTML, CSS, Git, and GitHub.

## Features

- First name input field
- Second name input field
- Email address input field
- Contact number input field
- Course selection dropdown
- Required field validation
- Register Now button
- Simple and clean design

## Technologies Used

- **HTML5:** Creates the structure of the form.
- **CSS3:** Styles the form and improves its appearance.
- **Git:** Tracks changes and maintains the project history.
- **GitHub:** Hosts the repository and supports collaboration through Pull Requests.

## Project Files

- `index.html` — Contains the student registration form.
- `style.css` — Contains the styling for the form.
- `README.md` — Provides information about the project.

## How to Run the Project

1. Download or clone the repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Fill in the registration form and choose a course.

## Git and GitHub Workflow

This project demonstrates the following workflow:

1. Create a Git repository.
2. Track project files and save commits.
3. Create a `form` branch for development.
4. Push the branches to GitHub.
5. Create a Pull Request from `form` into `main`.
6. Merge the Pull Request into `main`.

## Note

This is a front-end practice project. The form does not currently store student information in a database.
